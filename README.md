# Kado skills

Agent skills for [Kado](https://kado.so), a free search API for agents.

- `kado-search`: search with Kado and read its results.
- `kado-integrate`: add Kado search to a project's agent.

Install with the skills CLI:

```sh
npx skills add kado-so/skills
```

Or point your coding agent at <https://kado.so/start>.
